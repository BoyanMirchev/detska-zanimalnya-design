# Дизайн за детска занималня

Готов front-end дизайн с:

- Next.js
- React
- TypeScript
- Tailwind CSS v4
- Lucide React icons

## Стартиране

```bash
npm install
npm run dev
```

Отвори http://localhost:3000

## Забележка

Това е само дизайн. Телефонът, имейлът, името на занималнята и текстовете са примерни и трябва да бъдат сменени.
